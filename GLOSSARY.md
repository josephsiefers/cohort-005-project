# Cadence

Cadence sells online courses. Learners buy them as one-off Purchases and work through them lesson by lesson.

## Language

### Money back

**Refund Request**:
A buyer's request to get their money back for a Purchase. It is **Requested** until an admin moves it to **Approved** or **Declined**. "Open" is fine as everyday shorthand for a Refund Request that is still Requested.
_Avoid_: Chargeback, Reversal, Cancellation, cancel my purchase, pending

**Refund**:
Money for a Purchase going back to the buyer after their Refund Request is approved. A Refund also ends the buyer's access to that course.
_Avoid_: Reversal, Chargeback, Cancellation

**Cancellation**:
Stopping a recurring subscription so that access ends when the current payment period finishes. Cadence has no subscriptions today, so nothing is a Cancellation yet. The word is reserved for this meaning and is never a synonym for Refund.

## Flagged ambiguities

- **Chargeback** is a dispute the cardholder raises through their bank, which the merchant has no say in. A buyer asking us for their money back is a Refund Request, never a Chargeback.
- **Reversal** usually means voiding a card payment before it settles. Don't use it for a Refund.
- **Learner vs Student**: the code calls the person taking a course a "learner", while the issues say "Student" (and "Team Admin" for a team buyer). Not resolved yet.
